# About this journal

I'm Shishir. I hold a Master's degree in Cybersecurity and Cyber Defence from the University of Luxembourg and a Bachelor's in Computer Engineering.

I have studied a lot of theory. This journal is where I turn it into practice: building real systems, breaking them on purpose, troubleshooting them step by step, and explaining clearly what went wrong and why.

## The project

For 30 days I am building **VaultLab**, a basic zero-knowledge password manager, and hosting it on my own Ubuntu home server:

- **Frontend:** React, with encryption done in the browser using the Web Crypto API
- **Backend:** Node.js and Express, with PostgreSQL
- **Server:** Ubuntu, Nginx, HTTPS with my own certificate authority, a ufw firewall
- **Practice:** breaking each part on purpose and writing up how I found and fixed it

## How each post is written

Every post records what I built, what went wrong, the exact errors, what I first assumed, how I investigated, what fixed it, and what I learned. The goal is a troubleshooting handbook built from my own experience.
